# 深圳→大理/丽江7天自驾游规划系统

一个集成了高德地图实时交通和小红书热门攻略的智能自驾游规划系统。

## 🚗 项目特色

### 核心功能
- **高德地图集成**: 实时交通监控、海拔安全提醒、充电桩占用率
- **小红书攻略**: 瀑布流展示、实时搜索、热门内容推荐
- **智能行程规划**: 7天详细规划、按日折叠、安全提醒
- **响应式设计**: 支持桌面端和移动端，全屏模式

### 安全特性
- 海拔安全监控（禁止3000米以上夜驾）
- 疲劳驾驶防护（强制休息提醒）
- 实时交通预警（拥堵路段标识）
- 充电桩实时占用率监控

## 🛠️ 技术架构

- **前端框架**: Next.js 14 + React 18 + TypeScript
- **样式系统**: TailwindCSS + 自定义组件
- **图标库**: Lucide React
- **状态管理**: React Hooks
- **响应式设计**: CSS Grid + Flexbox

## 📱 功能模块

### 1. 高德地图组件 (MapComponent)
- 实时图层切换（地形、气象、充电桩）
- 智能标记点（景点、停车场、充电站、警告点）
- 实时交通监控
- 海拔安全提醒

### 2. 小红书内容组件 (XiaohongshuComponent)
- 瀑布流布局展示
- 智能搜索和筛选
- 地点和标签分类
- 互动数据展示（点赞、收藏）

### 3. 行程规划组件 (TripPlannerComponent)
- 7天行程概览
- 按日折叠详情
- 实时交通状态
- 安全提醒系统

## 🗺️ 行程规划详情

### D1: 深圳 → 南宁
- 避开早高峰，傍晚出发
- 汕昆高速百色段拥堵预警
- 南宁宵夜美食体验

### D2: 南宁 → 大理
- 全程高速，途经昆明
- 充电桩实时占用率监控
- 高原反应预防

### D3: 洱海环线
- 洱海西线骑行
- 喜洲古镇扎染体验
- 网红S弯拍照点

### D4: 大理 → 丽江（经停沙溪）
- 214国道沙溪段急弯标注
- 山路驾驶安全提醒
- 海拔继续升高

### D5: 玉龙雪山
- 海拔3150米，最高点
- 蓝月谷徒步路线
- 高原反应防护

### D6: 丽江 → 百色（极限返程）
- 避开杭瑞高速楚雄段
- 强制休息区设置
- 疲劳驾驶防护

### D7: 百色 → 深圳（截止00:00）
- 夜间模式导航
- 2小时强制休息提醒
- 安全抵达深圳

## 🚀 快速开始

```bash

```

## 🚨 安全提醒

### 驾驶安全
- 单日行车时间 ≤ 8小时（除D6）
- 避免3000米以上海拔夜间驾驶
- D6行程包含2个强制休息区
- D7截止时间00:00，注意时间安排

### 高原安全
- 甘海子：海拔3150米
- 玉龙雪山索道：海拔4506米
- 建议提前服用红景天
- 避免剧烈运动
